# Перевірка обчислень задачі Стіглера в GNU Octave через GLPK

Каталог містить обчислювальну перевірку розділу «Задача про дієту»
(`diet_corrected.tex`). Текст роботи не змінено і до репозиторію не додано:
числа з тексту записано як константи у `src/stg_compare.m` і використано лише
для порівняння. Усі підсумкові значення одержано з фактичних запусків GLPK.

## Запуск

```sh
cd research_nutrition
octave-cli --no-gui --quiet run_all.m 2>&1 | tee results/logs/console_full.log
```

Тривалість — кілька секунд. Потрібні лише GNU Octave з функцією `glpk`
(Ubuntu: `apt-get install octave`) і файли каталогу `data/`. Пакет
`glpk-utils` (`glpsol`) потрібен тільки для допоміжного журналу
`glpsol_stigler_mod.log`; без нього основні результати не змінюються.

Повідомлення бібліотеки GLPK надходять безпосередньо до стандартного виводу,
тому повний журнал зберігається через `tee`. Стислий журнал
`results/logs/run_summary.log` записується незалежно від способу запуску.

## Середовище фактичного запуску

| Компонент | Версія |
|---|---|
| GNU Octave | 8.4.0 (пакет `octave 8.4.0-1build5`, Ubuntu 24.04.5 LTS, x86_64) |
| GLPK (бібліотека, яку викликає `glpk`) | 5.0 (`libglpk.so.40`, пакет `libglpk40 5.0-1build2`) |
| `glpsol` (допоміжна перевірка) | 5.0 |

Версія 4.65 стосується лише файлу даних `stigler.mod`; розв'язувач — GLPK 5.0.

Параметри `glpk` (однакові для всіх задач): `lpsolver=1` (модифікований
симплекс-метод), `dual=1` (двофазний прямий), `presol=0`, `scale=16`,
`price=34`, `rtest=34`, `tolbnd=1e-9`, `toldj=1e-9`, `tolpiv=1e-10`,
`itlim=100000`. Запуск приймається лише за `errnum = 0` і `status = 5`.

Допуски подальших перевірок: порушення допустимості `1e-9`, двоїстий розрив і
умови доповняльної нежорсткості `1e-12`, носій `x_i > 1e-9`, активний рядок
`|s_j| <= 1e-9 max(1, |b_j|)`. Повний перелік — `results/csv/environment.csv`.

## Файли

```
run_all.m                 головний скрипт
glpk_appendix.tex         окремий документ XeLaTeX: абзаци й усі таблиці
src/
  stg_config.m            вектор b, параметри GLPK, допуски, параметри експериментів
  stg_load1939.m          читання stigler.mod (порядок стовпців перевіряється за назвами)
  stg_load1944.m          читання stigler1944.csv
  stg_tenths.m            цілочислове подання 10A, коефіцієнти «торгова одиниця -> фунти»
  stg_lp.m                один запуск glpk із перевіркою errnum і status; журнал запусків
  stg_base.m              пряма та двоїста задачі, узгодження знаків, перевірки
  stg_exact.m             точний сертифікат оптимальності та єдиності (цілі числа)
  bi*.m                   довга цілочислова арифметика (сума, добуток, визначник)
  stg_uniqueness.m        2n задач: межі координат на оптимальній грані
  stg_sensitivity.m       +1% для кожної вимоги і для всіх разом
  stg_redundancy.m        m_j для неактивних рядків; вилучення рядків із u_j = 0
  stg_units.m             z_i = 100 x_i / p_i, 365 і 365.25 дня, фунти
  stg_datacheck.m         перевірки нормування на долар
  stg_historic.m          історичні раціони; межі мінімуму за округлення коефіцієнтів
  stg_multiday.m          семиденні задачі, середні межі, максимізації з допуском
  stg_multiday_exact.m    точне порівняння середніх надходжень із межами
  stg_compare.m           значення з тексту роботи та їх порівняння з GLPK
  stg_write_csv.m, stg_write_compare.m, stg_tex.m, stg_paragraphs.m   вивід
results/
  logs/run_summary.log          стислий журнал результатів
  logs/console_full.log         повний вивід, зокрема повідомлення GLPK
  logs/glpsol_stigler_mod.log   допоміжний запуск glpsol на незміненому stigler.mod
  csv/                          таблиці з повною точністю (%.17g)
  tex/                          готові таблиці LaTeX і абзаци
source_check/                   звірка таблиць B і 2 зі сканом статті
```

- Усі 294 запуски GLPK завершено з `errnum = 0`, `status = 5`.
- Таблиця порівняння містить 164 рядки. 162 значення тексту, які не залежать
  від розв'язувача, підтверджено після округлення до наведеної кількості
  знаків. Два значення підрозд. 2.3 (`1.23e-15`, `2.02e-16`) є числовими
  похибками іншого розв'язувача; GLPK дає `5.95e-15` і `3.75e-16`.
- Семиденна задача: `C* = 0.796714750932` дол.; різниця із сумою добових
  мінімумів дорівнює 0. Межі заліза 12 і 62.03914 мг та білка 74.9 і
  158.66131 г зберігають `C*`; межі 65.14113 мг і 166.594 г дають
  `0.809187146386` і `0.815475723898` дол.
- Історичний підсумок 1944 року 59.88 дол. менший за `365 C* = 59.9005` дол.,
  бо історичний раціон покриває 99.82–99.91% вимог для кальцію, вітаміну A і
  вітаміну B2 за коефіцієнтами таблиці B. Для матриць, сумісних з округленням
  надрукованих коефіцієнтів, мінімум за 365 днів лежить між 59.6902 і
  60.1122 дол.

## Межі перевірки

- Числові результати GLPK одержано в арифметиці подвійної точності з
  наведеними допусками. Строгі твердження (оптимальність, єдиність `x*` і
  `u*`, збереження базису за +1%, порівняння середніх надходжень із межами)
  спираються на перевірку знаків цілих чисел у `src/stg_exact.m` і
  `src/stg_multiday_exact.m`, а не на числові розв'язки.
- Точні твердження стосуються десяткових коефіцієнтів зазначених файлів, а не
  неокруглених харчових даних.
- Результати допоміжних максимізацій за бюджету `0.79671475 + 1e-7` є
  результатами з допуском до вартості.
- Звірку зі сканом виконано одним читанням зображень сторінки; для рядків
  № 78–80 таблиці B немає арифметичної перевірки за таблицею A (див.
  `source_check/SOURCE_CHECK_NOTES.md`).
- У `stigler.mod` їстівна маса кукурудзяного сиропу (4996 г на долар) не
  узгоджується з ціною та одиницею (4966.4 г); цей стовпець до моделі не входить.
